# Multimodal Validation Gates

The following gates must hold for every change touching the multimodal stack.  Metrics are generated by the helper scripts under `scripts/` and enforced via `tests/test_validations.py`.

## Embedding Alignment
- **Goal:** Cross-modal embeddings must remain tightly aligned.
- **Metric:** Cosine similarities between the unified Vision/Audio/Text projections as produced by `run_unified_embedding_eval.py`.
- **Gate:** `vision_audio`, `vision_text`, and `audio_text` cosine scores must each be **≥ 0.95**.

## Sequential Learning
- **Goal:** Surprise-prioritised replay should minimise catastrophic forgetting.
- **Metric:** Average forgetting percentage emitted by `run_seq_learning_eval.py`.
- **Gate:** Average forgetting with replay must be **≤ 0.5%**.

## Adapter Efficiency
- **Goal:** LoRA adapters should dramatically reduce trainable parameters.
- **Metric:** Parameter reduction fraction from `run_lora_efficiency_eval.py`.
- **Gate:** LoRA reduction must be **≥ 95%** versus dense fine-tuning.

## Landmark Attention Throughput
- **Goal:** Landmarking must accelerate long-context inference.
- **Metric:** Speedup curve reported by `run_landmark_eval.py`.
- **Gate:** Speedup at sequence length **2048** must be **≥ 16×**.

Keep this document in sync with any future validation updates.
